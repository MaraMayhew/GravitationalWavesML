This repo contains code to create a Decision Tree based ML model for classifying gravitational waves with low signal to noise ratio. 

To start you can run the feature engineering script that will take the gravitational wave data and convert it into values to be used by the model. 
This script takes about 20 minutes to run and runs off of data too large to be directly uploaded here, but can be downloaded through this link: https://drive.google.com/file/d/1sEoN70iYrdVTWv_czozchwkmwVe2p2F2/view?usp=sharing. 
This note book outputs the features and targets used to train the model in CSV form. A copy of these output CSVs are in the repo and can be accessed without running the script. 

To train and create the Decision Tree Models you can run the DTModels notebook.
